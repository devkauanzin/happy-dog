# Happy Dog — site

Landing page estática feita com HTML, CSS e JavaScript. Não precisa instalar dependências nem executar um processo de build.

## Arquivos

- `index.html` — conteúdo da página
- `styles.css` — estilos e layout responsivo
- `script.js` — menu móvel e ano do rodapé

## Publicar

Envie os arquivos desta pasta para o repositório GitHub. Para hospedagem estática, configure o provedor para servir `index.html` como página inicial. As fotos são carregadas da CDN do Unsplash e exigem conexão com a internet.
